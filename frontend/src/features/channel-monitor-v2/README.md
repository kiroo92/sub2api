# 渠道监控卡片视图

管理接口说明见 [渠道监控 V2 Admin API](../../../../docs/ADMIN_CHANNEL_MONITOR_V2_API.md)。

移植自 [kiss-kedaya/sub2api](https://github.com/kiss-kedaya/sub2api/tree/9cc3c744be5be27b888e7d4e91335c72c3c8a55c) 的渠道监控 V3 前端，沿用项目的 LGPL-3.0-or-later 许可。

在系统设置中启用渠道监控并选择 V2 被动监控后，原渠道状态入口默认展示卡片视图。监控分组、平台、刷新频率仍在现有渠道监控管理页面配置。V1 主动探活视图保持原样；访问渠道状态时加上 `?monitor_view=v2` 可查看原 V2 视图。

新增平台/分组卡片、时间轴、缓存率、可用率、首 Token 延迟和用户倍率，支持 90 分钟、24 小时、7 天、30 天。卡片指标使用最新监控时间桶，时间轴展示所选范围。样式限定在监控页面，兼容明暗主题。

本次仅迁移前端，复用现有 `/channel-monitor-v2` 和用户分组接口及权限过滤，不涉及数据库迁移或后端统计口径变更。
