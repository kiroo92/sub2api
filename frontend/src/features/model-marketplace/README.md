# 模型广场与渠道状态

登录后的 `/model-marketplace` 合并模型分组价目与渠道监控 V2，用户侧边栏的模型广场入口指向此页。原公开 `/model-plaza` 与 `/monitor` 保留。

- 以 `/model-plaza` 返回的分组为准，沿用模型广场启用开关；按分组 ID 关联用户 `/channel-monitor-v2/matrix?group_by=platform_group`。不使用管理员接口或分组名称猜测关联。
- 一个分组对应多个监控平台时分行展示，不对脱敏后的指标做未经加权的平均。
- 状态条按 `requested_start` / `requested_end` / `bucket_seconds` 对齐，缺失时间桶保留为灰色。条内细纹仅是视觉样式，每个可聚焦时间桶仍对应一条原始记录。
- 可用率遵循 V2 的 `1 - error_rate` 口径与错误忽略规则。用户响应中计数被脱敏为 0，因此通过保留的健康状态区分有效指标和样本不足。
- 默认 24 小时，支持 90 分钟、7 天、30 天。按监控配置自动刷新；切换范围取消旧请求，后台标签暂停刷新，离开页面清理请求与定时器。
- 模型和状态独立加载；状态失败不隐藏定价。刷新失败标注旧数据，缺失或关闭监控不显示虚构可用率。
- 展开的定价使用与旧广场共用的 `PlazaGroupPricing`，保留用户倍率、图片倍率、高峰说明和长上下文计费规则。
